# 安全边界说明（SECURITY-NOTES）

> 本文是安全边界的**精简说明**，便于部署前快速确认。完整安全模型、威胁分析与报告渠道见仓库根目录 [SECURITY.md](../SECURITY.md)。
>
> 相关文档：[FAQ](FAQ.md) · [部署与运维指南](DEPLOYMENT.md)

## 一句话概括

**只读挂载、不执行删除、所有删除动作由人手工完成；导出前必须通过复核。**

## 1. 只读保证

- 扫描目录必须以 `:ro` 只读方式挂载，容器不要求、也不应获得 NAS 写权限；
- 启动时对每个扫描根做**写探测**，并向下抽样（深度 ≤3、最多 20 个子目录）；只要有一处能创建文件就拒绝启动（退出码 2）；
- 运行期每 `GUARD_INTERVAL_SECONDS`（默认 1800 秒）复查一次；发现扫描根变为可写会置为 unsafe，扫描、生成方案、导出全部返回 409；
- 容器以非 root 身份运行，rootfs 只读，`cap_drop: ALL`，`no-new-privileges: true`。

## 2. 不提供的操作

工具**没有**以下接口或能力：

- 删除、移动、改名文件；
- 写入、截断、修改 NAS 上的任何文件；
- 回收站、撤销、批量执行系统命令；
- 对外发送文件、清单或遥测数据。

页面上的“删除方案”只是待删清单，真正的删除由你在 NAS 上按清单手工执行。

## 3. 人工删除前的闸门

1. 审核时每组必须至少保留 1 份，否则不能进入删除方案；
2. 生成方案时逐项重新核对 size/mtime/SHA-256，变化或缺失的条目标记为需复核；
3. 只有状态为 `final`（已通过复核）的清单才允许导出；其他状态返回 409；
4. 导出前再次验证“保留份”仍然存在且未被修改，任何异常都会拒绝整份导出；
5. 导出的 CSV/JSON/HTML 都带有“本工具不会执行删除，请手工核对”的说明。

## 4. 认证与会话

- 默认 `AUTH_MODE=password`：首次启动生成一次性初始化令牌（`DUPE_SETUP_TOKEN` 或 `data/setup_token`，权限 0600），设置口令后令牌自动删除；口令使用 bcrypt 存储；
- 登录失败默认限流 5 次/分钟/IP；
- 会话为签名的 HttpOnly Cookie（默认 8 小时），写请求需要 CSRF Token；注销会使旧会话失效；
- 令牌错误或缺失统一返回 403，不透露初始化状态；
- `AUTH_MODE=none`：免登录，仅适合完全可信的内网；仍签发 CSRF 会话，任何能访问端口的人可查看清单、触发扫描、导出清单，但**没有删除/写入执行能力**。不要暴露到公网，也不要在公网反代后使用。

## 5. 数据与隐私

- 无遥测、无云调用，不访问外部网络；
- 扫描只读取文件元数据并计算哈希；索引保存路径、大小、时间、SHA-256 等元数据，**不保存文件内容**；
- 数据库、导出文件、日志都保存在本地 `./data`；
- 日志与导出不包含口令和会话密钥；首次初始化的令牌会打印到启动日志（这是获取令牌的途径），设置口令后立即失效并从数据目录删除。

## 6. 已知边界

- 工具无法阻止有 NAS 权限的人绕过本工具手工误删文件；本工具不是备份/回收站；
- 从审核、生成方案、导出到真正手工删除之间存在时间差；期间文件若变化，仍以 NAS 实际状态和导出后的再次核对为准；
- 同名候选不等于内容重复，必须人工确认；
- `AUTH_MODE=none` 会把“查看清单、触发扫描、导出清单”暴露给任何能访问端口的人；
- 不提供病毒扫描、内容合规检查或文件预览；哈希只用于判重，不代表内容安全；
- 单用户模型，不支持多租户或细粒度权限。

## 7. 报告安全问题

请按 [SECURITY.md](../SECURITY.md) 中的渠道**私下**报告，不要在公开 Issue 中披露可利用细节、真实路径、令牌或口令。报告时建议附上版本（`/api/v1/system/version`）、影响范围、复现步骤和必要的脱敏日志。
